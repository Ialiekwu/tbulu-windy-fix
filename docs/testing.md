## 自动检查

运行 `python3 scripts/bootstrap.py` 后执行 `bash scripts/test.sh`：

- 检查只匹配 Windy 的 HTTPS 瓦片域名和路径，拒绝相似域名、其他协议、其他端口和 URL 用户信息。
- 检查请求头补全、已有错误 Referer 替换，以及 URL、方法、请求体、标签和其他请求头保持原状。
- 检查重复执行和非目标请求的行为。
- 使用临时测试密钥检查签名身份匹配、错误身份拒绝、缺失密钥不自动生成、密码文件缺失和错误别名。

测试使用 OkHttp 4.12.0；它是测试依赖，不打包进模块。测试不能代替真机 LSPosed 注入和网络下载验证。

## 重新进行真机验证

1. 在 LSPosed 启用模块并仅勾选两步路，强制停止两步路后重新打开。
2. 选择 Windy 图层，在未缓存区域建立一个很小的离线下载任务。
3. 确认任务完成，并检查模块日志是否出现请求补全及 `HTTP 200 image/png`。
4. 暂时断网，重新进入下载区域并拖动、缩放，确认地图显示。
5. 清理临时任务时，保留用户已有的离线地图。
