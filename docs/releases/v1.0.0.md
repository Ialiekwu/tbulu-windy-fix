首个公开版本：为两步路的 Windy 地图瓦片请求补全 Referer，使已验证环境下的在线显示和原生离线下载恢复工作。

下载下方的 **windyfix-1.0.0.apk**，安装后在 LSPosed 中启用，作用域只勾选“两步路户外助手”，然后强制停止并重新打开两步路。需要已 root 且 LSPosed 正常工作的手机；只有 KernelSU 不足以运行模块。

已验证 Android 16、LSPosed 2.1.1 (7790)、两步路 9.2.3 (1620)：原生四瓦片任务下载 4/4 成功，均返回 HTTP 200，PNG 校验通过。其他版本需要自行验证。

模块独立安装，保留两步路原始 APK 和签名。正式 APK 沿用首次真机安装时的密钥，后续版本维持该身份。签名证书 SHA-256：

```text
abf6ed8fe23f7e72df41caf2749a1ca160c3a22ef3e7273d2c6a36fbb6525122
```

本版 APK 文件 SHA-256：

```text
daa33cd740a5cf55154aec60b9458ad59b0c516da8ed77ce849fda1a26addc56
```

附带 `SHA256SUMS`、`certificate.sha256` 和 `signature.txt`，可用于下载与签名核验。源代码见仓库或 GitHub 自动生成的 Source code 压缩包。Actions 的未签名构建仅供开发检查，不能直接安装。

本版为 LSPosed 模块，不含 LSPatch 集成的两步路 APK。新建图源的名称/URL 限制仍由两步路决定，未来图源服务规则变化也可能影响可用性。
